# IGCSE Syllabus Tracker
IGCSE Syllabus Tracker is made using html css and react.
This is a igcse syllabus tracker it has check list of subject chapters that saves on your browser even after referesh. 
Record sections allows you to record the subjects and date so you know what subjects you did and when you did certain subjects
Exam countdown shows a flip clock countdown timer of the final exams.
Here is the link: https://igcse-syllabus-tracker.vercel.app/#subjects
