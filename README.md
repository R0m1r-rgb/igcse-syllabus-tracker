# IGCSE Syllabus Tracker

A modern, client-side web application engineered to help Cambridge IGCSE students track revision progress, log study sessions, and monitor final examination schedules in real time.

🚀 **Live Demo:** [igcse-syllabus-tracker.vercel.app](https://igcse-syllabus-tracker.vercel.app/#subjects)

---

## Key Features

* **Persistent Syllabus Checklist:** Interactive progress tracking for IGCSE subject modules with automatic state retention using Browser Local Storage (`localStorage` API).
* **Study Session Logging:** Dedicated recording module to log specific subjects and completion dates for structured revision auditing.
* **Real-Time Exam Countdown:** Animated flip-clock countdown timer displaying exact time remaining until Cambridge final examinations.
* **Responsive Architecture:** Accessible across desktop, tablet, and mobile browsers.

---

## Tech Stack

* **Frontend:** React.js, JavaScript (ES6+)
* **Styling:** CSS3 (Flexbox/Grid layout)
* **Markup:** HTML5
* **State & Persistence:** React Hooks (`useState`, `useEffect`), Web Storage API (`localStorage`)
* **Deployment:** Vercel CI/CD pipeline
